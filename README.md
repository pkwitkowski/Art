# Art

SlowBooks Pro branding assets.

The package contains eight turtle poses, ten interchangeable expressions, light and dark variants using #257321 and #6CC46A, hare and $BP icons, transparent 2048px PNGs and editable SVG masters.

The artwork is a vector reconstruction of the approved raster mascot, with drawing differences from the original illustration.

Downloadable artwork is published in this repository’s Releases section.
